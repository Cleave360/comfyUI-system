# Roadmap

## Vision
To establish a fully functional, auto-healing digital design studio capable of holding ~65GB of FP16 uncompressed models dynamically in memory at any given time.

## Phases
1. **Foundation**: Build the environment, uncap memory bounds, verify M3 API calls via Python wrappers.
2. **Integration**: Install ComfyUI-Manager natively, tie in Swarm messaging and Gemini Model Context Protocol (MCP) bridges.
3. **Multi-Model Orchestration**: Develop the 'Master Template' hybrid workflows linking FLUX Base and SDXL directly.
4. **Rust Perception Bridge**: Enable spatial reasoning and video-generation loops using local vision LLMs interacting directly with ComfyUI generation frames.
